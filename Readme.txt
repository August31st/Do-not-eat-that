此项目为边缘世界模组
目前已完成

功能：

自定义触发阈值（默认为智力高于8或者烹饪高于6）

流程：食物中毒发生后->高于阈值->检测出食物有毒->呕吐，此次食物不增加营养值->根据心情状态触发摔碗->添加心情减益
                    ->低于阈值->根据技能和阈值的比值概率触发（选择两种技能中比值较高者）->成功触发转至食物有毒处理
                                                                                        ->失败，进入原版有毒事件
特性联动：嗜血：摔碗触发不会根据心情状态判断，始终触发
          善良：不会触发摔碗且无心情减益
          苦行者：检测食物有毒后依旧食用，获得更高心情减益
          受虐狂：吃得很开心（
          贪食者：根据进食能力在检测出食物有毒后再次判定，成功后正常吐出，失败则咽下，成功几率随进食能力增加而线性减小
          体弱多病：根据消化能力在检测出食物有毒后再次判定，成功后正常吐出，失败则吐出但仍然中毒，成功几率随消化力增加而线性增加
